# Cloud Computing Project (Azure)

This repository contains the finished Cloud Computing project. Below is a concise summary of what I implemented and configured in Azure and Azure DevOps.

- Created an Azure Resource Group containing all project resources.  
- Provisioned an Azure Virtual Machine and configured it as a self-hosted Azure DevOps agent.  
- Deployed SQL Server and an Azure SQL Database (Basic tier, 5 DTU).  
- Implemented an Azure Function App with at least two functions using triggers.  
- Deployed the existing web application to an Azure Web App.  
- Created an Azure Key Vault and stored all connection strings and secrets there.  
- Provisioned an Azure Storage Account for the application.  
- Pushed all source code and pipeline definitions to Azure Repos (Git).  
- Created tasks in Azure Boards to plan and track work for the project.  
- Configured Azure Pipelines to run CI/CD with automatic triggers.
